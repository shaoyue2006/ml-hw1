# 共享单车基础回归模型报告

本阶段使用 13,915 条开发训练记录比较四种固定配置的回归模型。所有结果来自训练集内部的五折扩展窗口时间验证，不是独立测试集成绩。当前梯度提升树的平均 RMSE 最低，作为 C 阶段的主要优化起点。

## 实验设置

目标为每小时总租赁量 cnt，使用 A 提供的 12 个天气与日历特征，不使用 casual、registered、instant 或原始日期作为模型输入。四种模型共用特征白名单与整日验证折，每折独立拟合预处理。保留全部原始预测，包括负值；不取整、不事后截断。

配置见 `../configs/baseline.toml`。随机种子 42；Ridge 的 alpha=1、lsqr 求解器；Poisson 的 alpha=0.1、最多 2000 次迭代；决策树最大深度 12、叶节点最小 10 条；提升树学习率 0.05、200 轮、最多 31 个叶节点、最大深度 6、L2=1，关闭自动早停。这些是基础起点，尚非最优参数。

## 方法原理

- Ridge：最小化平方误差与 L2 系数惩罚，提供正则化加性线性基线。正则化可稳定相关特征的估计，但不会自动构造非线性和交互。
- Poisson：通过对数链接建模条件均值，预测均值为正；同样采用 L2 正则。适用于研究计数建模，但计数目标不保证满足 Poisson 分布假设，当前不进行系数显著性推断。
- 决策树：通过特征条件分裂拟合分段常数，可自动表达非线性与交互；复杂度由深度和叶节点样本数限制。
- 梯度提升树：按损失的梯度信息逐步增加树，基础版采用平方误差，改善组合模型的拟合。学习率、树复杂度和迭代次数共同影响泛化。

## 验证结果

以下为各折指标的算术平均与样本标准差，标准差反映不同时间段的变化，不是置信区间。主指标为平均 RMSE。

## 分析与限制

梯度提升树的平均 RMSE 相比 Ridge 降低约 18.49%，但尚未完成独立测试评价，不能据此宣称对未来时段一定最好。Poisson 的平均 MAE 小于 Ridge，而 RMSE 略大；不同指标揭示不同取舍。Poisson 最后一折 RMSE 为 170.72，需进一步检查大误差的来源。

决策树平均验证 RMSE 为 115.34，没有优于 Ridge。非线性模型不保证优于线性模型；当前树复杂度、特征编码和时间分布变化都可能影响结果，需要控制变量实验。

平均训练 RMSE 与平均验证 RMSE 如下。两者存在差距，提示有必要分析模型复杂度和时间变化，但不能仅据此给出单一原因。

| 模型 | 训练 RMSE 折均值 | 验证 RMSE 折均值 |
| --- | ---: | ---: |
| ridge | 69.14 | 108.84 |
| poisson | 61.70 | 110.46 |
| decision_tree | 56.97 | 115.34 |
| gradient_boosting | 35.71 | 88.71 |

Ridge 产生 364 个负预测，平方误差提升树产生 132 个负预测；Poisson 与决策树在本次验证中没有负预测。暂不截断以保证基础实验规则固定，C 可单独比较预先定义的后处理或 Poisson 损失。

早期训练窗口不覆盖全部月份和年份，部分验证类别未出现过；独热编码按约定忽略未知类别。这是时间验证的现实限制，不能通过预先在全量数据学习类别来规避。当前仅比较固定参数，模型排名不能推广为算法普遍排名。天气是假定预测时已知的历史天气，本实验不等同于部署时使用天气预报的效果。

## 复现与后续

在项目目录运行 `uv sync --locked` 和 `uv run --locked bike-train --model all`。完整模型、逐条验证预测、分组误差和图表生成在本地 `artifacts/runs/`，不纳入 Git。每次运行独立保存配置及数据、源代码和锁文件哈希。

C 的优化方向和统一评价约定见 [交接说明](handoff_to_c.md)。本阶段没有从零实现模型、没有训练神经网络，也没有通过测试集选择参数。
