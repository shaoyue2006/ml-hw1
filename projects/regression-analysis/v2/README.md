## 复现两组诊断实验

在本目录运行以下命令，使用 v1 锁定的 Python 3.12 环境与 `configs/baseline.toml` 参数。

```shell
uv run --project ../v1 --locked python reproduce.py
```

脚本在相同五折上分别运行 v1 Ridge、Ridge 加小时与工作日交互、v1 梯度提升树和原生类别提升树。每折仅用该折训练数据拟合预处理和模型，以原始预测计算指标。

- [逐折指标](results/fold_metrics.csv)包含训练截止日期、验证日期范围、样本数和各折误差。
- [汇总指标](results/summary_metrics.csv)包含五折算术均值、折间样本标准差，以及拼接验证预测后的绝对误差总和与真实需求总和之比。
- [运行记录](results/run_metadata.json)包含具体配置、环境版本及输入文件哈希。逐小时预测另存在本地 `artifacts/validation_predictions.csv.gz`。再次运行会更新这些输出。

### 本次复现结果

| 对照 | v1 平均 RMSE | v2 平均 RMSE | RMSE 降幅 | v2 平均 MAE | v2 平均 R² |
| --- | ---: | ---: | ---: | ---: | ---: |
| Ridge 加小时与工作日交互 | 108.84 | 88.73 | 18.48% | 65.84 | 0.693 |
| 梯度提升树改用原生类别 | 88.71 | 78.06 | 12.01% | 52.47 | 0.740 |

降幅使用同次重跑的未取整折均值计算。按[原诊断记录](diagnostic_results.md)的显示精度，四种配置的 12 个汇总值及两组改进方案的 20 个分折 MAE、RMSE 均吻合。四种配置各自覆盖同样的 11,608 条验证记录，独立测试集的 3,464 条记录保留至最终评价。

## 最初交接的证据与改进方向

| 优先级 | 改进内容 | 目的 | 诊断依据 |
| --- | --- | --- | --- |
| 1 | Ridge、Poisson 增加“小时×工作日”交互 | 表达不同日期类型的小时需求曲线 | Ridge 的小型对照中平均 RMSE 从 108.84 降至 88.73 |
| 1 | 梯度提升树使用原生类别处理 | 让树更直接地利用类别组合 | 小型对照中平均 MAE 从 63.76 降至 52.47 |
| 2 | 调整正则化与模型复杂度 | 平衡拟合和时间泛化 | 结合各折训练与验证差距进行选择 |
| 2 | 比较提升树平方误差与 Poisson 损失 | 研究计数预测、高峰与低谷误差 | 分组误差为损失选择提供参照 |
| 3 | 分析不同时间段、工作日类型和需求水平 | 定位改进发生的具体场景 | 重点检查 Poisson 最后一折的高估记录 |

诊断数值的完整口径见 [小型实验结论](diagnostic_results.md)。

## 建议的实施顺序

1. 以 v1 的固定参数和时间验证结果为参照，分别复现交互特征、原生类别处理两组对照。
2. 每组先改变一个主要因素，保存配置和分折指标，明确改善来源。
3. 在验证过的特征与预处理基础上进行小范围参数搜索。
4. 保存改进后的四模型结果，生成相对 v1 的指标变化和图表。
5. 配置冻结后，统一进行最终测试评价。

## 建议补充的版本材料

v2 实现时可参考 v1 的 `src/`、`configs/`、`tests/`、`reports/` 和 uv 环境组织方式，保留算法独立文件与统一评价流程。

每轮实验记录：改动内容、选择理由、基准版本、配置、数据与划分、分折 MAE/RMSE/R²、均值与标准差、运行位置、Git 提交、改善幅度及现象分析。

| 比较项目 | 记录方式 |
| --- | --- |
| MAE、RMSE 变化 | 当前版本指标减去基准指标 |
| MAE、RMSE 改善比例 | （基准指标－当前指标）÷基准指标 × 100% |
| R² 变化 | 当前版本 R² 减去基准 R² |
| 场景表现 | 分别记录高峰、低谷、工作日及非工作日误差 |

同一算法按版本比较，使用相同数据与五折时间验证规则。v1 保留原始方案，v2 保存本轮改动；后续版本继续记录相对 v1 与上一版的变化。
