# v2 小型诊断实验结论

## 实验背景

第一轮梯度提升树的平均 MAE 为 63.76、平均 RMSE 为 88.71。为识别改进来源，在开发训练集内进行了两组小型控制变量实验，结论用于指导 v2 的正式开发。

## 比较条件

- 使用 v1 的同一原始数据、13,915 条开发训练记录和五折整日时间验证。
- 每折独立拟合预处理和估计器。
- 保留基础模型的超参数，分别改变一个主要建模因素。
- MAE、RMSE、R² 采用各折指标算术平均。
- 独立测试集留作配置冻结后的最终评价。

## 对照结果

| 模型方案 | 平均 MAE | 平均 RMSE | 平均 R² | 相对对应 v1 的 RMSE 改善 |
| --- | ---: | ---: | ---: | ---: |
| v1 Ridge | 80.58 | 108.84 | 0.545 | 基准 |
| Ridge 增加小时与工作日交互 | 65.84 | 88.73 | 0.693 | 约 18.5% |
| v1 梯度提升树（独热编码） | 63.76 | 88.71 | 0.685 | 基准 |
| 梯度提升树（原生类别处理） | 52.47 | 78.06 | 0.740 | 约 12.0% |

原生类别处理对照的 MAE 相对 v1 下降约 17.7%。绝对误差总和与真实租赁量总和之比约从 32.8% 降至 27.0%，该比例按拼接后的验证预测计算。

## 两组改动

### Ridge 的小时与工作日交互

将小时和工作日标记组合成一个类别特征，与原 12 列共同输入。类别独热编码和数值标准化均在各训练折拟合；Ridge 的 alpha、求解器与容差沿用 v1。

这一对照支持“日期类型与小时的交互关系影响预测表现”的判断，为后续线性模型特征工程提供依据。

### 梯度提升树的原生类别处理

四个连续天气特征保留数值，八个类别特征在训练折内进行序数编码，并通过 `categorical_features` 显式标记为类别。验证期的新类别映射为未知值，由估计器处理。学习率、树深度、叶节点数、迭代次数和正则化沿用 v1。

该对照支持“类别表达方式影响当前提升树效果”的判断，适合作为 v2 的优先复现实验。
